资源嗅探下载器 (Resource Sniffer Downloader)

最后更新日期：2026年6月5日

📋 摘要

资源嗅探下载器是一个浏览器扩展，用于检测和下载网页中的资源。我们非常重视您的隐私，本扩展不收集、不存储、不传输任何用户数据。所有数据都存储在您的本地设备上。

1. 数据收集

1.1 我们不收集的数据

本扩展不会收集以下数据：

  • 个人信息（姓名、邮箱、电话等）
  • 浏览历史记录
  • 网页内容
  • 下载的文件内容
  • 设备信息
  • 位置信息
  • Cookie 或跟踪数据

1.2 本地存储的数据

本扩展仅在您的设备本地存储以下数据：

  • 用户设置：您的个性化配置（如检测的资源类型、下载路径等）
  • 下载历史：您下载过的资源记录（仅保存在本地）
  • 资源缓存：当前页面检测到的资源列表（临时存储）

这些数据不会上传到任何服务器，仅用于扩展的正常功能。

2. 权限使用说明

本扩展需要以下权限才能正常工作：

权限 用途 说明
webRequest 检测网络请求 监听网络请求，识别可下载资源的 URL。不会收集或传输任何数据。
downloads 下载资源 将用户选择的资源下载到本地。仅在用户主动点击下载按钮时触发。
tabs 获取标签页信息 获取当前标签页的 URL，用于检测该页面的资源。不会访问其他标签页。
storage 存储设置 保存用户设置和下载历史。所有数据存储在本地，不会上传。
activeTab 访问当前标签页 仅在用户点击扩展图标时访问当前标签页。不会自动访问其他页面。

⚠️ 重要说明

本扩展不会在后台运行或自动收集数据。所有功能都由用户主动触发，扩展仅在您点击图标或选择资源时才会工作。

3. 数据存储与安全

3.1 本地存储

所有数据都存储在您的浏览器本地存储中：

  • 使用 Chrome Storage API 存储设置
  • 数据仅保存在您的设备上
  • 卸载扩展时，所有数据会被删除

3.2 数据安全

由于所有数据都存储在本地，不存在数据泄露的风险：

  • 没有数据传输到外部服务器
  • 没有第三方服务集成
  • 没有广告或跟踪代码
  • 完全开源，代码透明

4. 第三方服务

本扩展不使用任何第三方服务：

  • 没有分析服务（如 Google Analytics）
  • 没有广告网络
  • 没有社交媒体跟踪
  • 没有云存储服务
  • 没有外部 API 调用

5. 儿童隐私

本扩展不收集任何个人信息，包括儿童的个人信息。本扩展适合所有年龄段的用户使用。

6. 用户权利

6.1 数据控制权

您对本地存储的数据拥有完全控制权：

  • 查看数据：在扩展设置页面查看所有存储的数据
  • 删除数据：清除下载历史或重置所有设置
  • 导出数据：导出设置配置文件
  • 导入数据：导入之前导出的设置

6.2 卸载扩展

卸载本扩展会自动删除所有本地存储的数据。您也可以在卸载前手动清除数据。

7. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，并更新"最后更新日期"。

重大变更时，我们会在扩展更新说明中通知用户。

8. 合规声明

本扩展遵守以下隐私法规：

  • GDPR（通用数据保护条例）：不收集个人数据，无需用户同意
  • CCPA（加州消费者隐私法案）：不出售或共享个人信息
  • COPPA（儿童在线隐私保护法）：不收集儿童个人信息
