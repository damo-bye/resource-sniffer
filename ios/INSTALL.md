# iOS 快捷指令安装指南

本指南将帮助您在 iPhone 或 iPad 上安装和使用资源嗅探下载器快捷指令。

## 📋 前提条件

### 设备要求
- **设备**：iPhone 或 iPad
- **系统**：iOS 14.0 或更高版本
- **存储空间**：至少 50MB 可用空间

### 应用要求
- **快捷指令 App**：iOS 内置应用（通常已预装）
- **Safari 浏览器**：用于网页资源嗅探
- **文件 App**：用于管理下载的文件

### 权限要求
- **网络访问**：需要访问网络下载资源
- **文件访问**：需要保存下载的文件
- **Safari 访问**：需要读取当前网页内容

## 🚀 安装步骤

### 步骤 1：启用不受信任的快捷指令

由于安全原因，iOS 默认不允许安装不受信任的快捷指令。需要先启用此选项：

1. **打开设置 App**
   - 在主屏幕找到"设置"图标
   - 点击打开

2. **进入快捷指令设置**
   - 向下滚动，找到"快捷指令"
   - 点击进入

3. **启用不受信任的快捷指令**
   - 找到"允许不受信任的快捷指令"选项
   - 打开开关
   - 系统会要求输入密码或使用 Face ID/Touch ID 确认

4. **确认启用**
   - 在弹出的对话框中点击"允许"
   - 完成设置

> **注意**：如果找不到此选项，可能是因为：
> - iOS 版本过低（需要 iOS 14+）
> - 从未运行过快捷指令（先打开快捷指令 App 运行一次）

### 步骤 2：下载快捷指令文件

#### 方法 A：从 GitHub 下载（推荐）

1. **打开 Safari**
   - 在 iPhone/iPad 上打开 Safari 浏览器

2. **访问项目页面**
   - 访问本项目的 GitHub 页面
   - 导航到 `ios` 目录

3. **下载文件**
   - 找到 `ResourceSniffer.shortcut` 文件
   - 点击下载
   - 文件会保存到"文件" App 的"下载"文件夹

#### 方法 B：通过 AirDrop 接收

1. **从其他设备发送**
   - 使用 Mac 或其他 iPhone 通过 AirDrop 发送快捷指令文件

2. **接收文件**
   - 在 iPhone/iPad 上接收 AirDrop 文件
   - 选择"打开"或"保存到文件"

#### 方法 C：通过邮件/消息接收

1. **接收文件**
   - 通过邮件或消息应用接收快捷指令文件

2. **保存文件**
   - 长按附件
   - 选择"保存到文件"
   - 选择保存位置

### 步骤 3：安装快捷指令

1. **打开快捷指令 App**
   - 在主屏幕找到"快捷指令"图标
   - 点击打开

2. **进入我的快捷指令**
   - 点击底部的"我的快捷指令"标签
   - 确保在"所有快捷指令"视图

3. **导入快捷指令**
   - 方法一：点击右上角的 "+" 按钮，选择"添加不受信任的快捷指令"，然后选择下载的文件
   - 方法二：直接在"文件" App 中点击下载的 `.shortcut` 文件，系统会自动打开快捷指令 App 并提示安装

4. **确认安装**
   - 系统会显示快捷指令的预览和权限要求
   - 查看快捷指令的动作列表
   - 点击"添加不受信任的快捷指令"

5. **允许权限**
   - 首次运行时，系统会请求各种权限
   - 点击"允许"授予必要的权限

### 步骤 4：添加到共享表单（可选）

为了方便使用，可以将快捷指令添加到 Safari 的共享表单：

1. **打开快捷指令 App**
   - 找到已安装的"资源嗅探下载器"快捷指令

2. **编辑快捷指令**
   - 长按快捷指令图标
   - 选择"详细信息"

3. **添加到共享表单**
   - 找到"在共享表单中显示"选项
   - 打开开关
   - 选择要显示的位置（建议选择 Safari）

4. **保存设置**
   - 点击"完成"保存设置

## 📖 使用方法

### 基本使用流程

1. **打开 Safari**
   - 在 iPhone/iPad 上打开 Safari 浏览器
   - 浏览包含资源的网页（如视频网站、图片网站等）

2. **等待页面加载**
   - 确保页面完全加载
   - 某些资源需要滚动页面才能加载

3. **调用快捷指令**
   - 方法一：点击底部的"分享"按钮（方框带箭头图标），在分享菜单中找到"资源嗅探下载器"
   - 方法二：如果添加了共享表单，直接在分享菜单中点击

4. **选择资源**
   - 快捷指令会自动检测页面中的资源
   - 显示资源列表，按类型分类（视频、音频、图片等）
   - 选择要下载的资源

5. **下载资源**
   - 选择下载位置（iCloud Drive 或本地存储）
   - 等待下载完成
   - 可以选择打开或分享下载的文件

### 高级功能

#### 批量下载
- 选择"下载全部"选项
- 快捷指令会下载所有检测到的资源

#### 按类型筛选
- 选择"按类型选择"选项
- 先选择资源类型（视频、音频、图片等）
- 再选择具体的资源

#### 资源预览
- 下载前可以预览资源
- 使用 Quick Look 查看文件内容
- 确认无误后再下载

#### 分享资源
- 下载后可以选择分享
- 支持 AirDrop、微信、QQ、邮件等
- 可以保存到"文件" App 的其他位置

## 🔧 故障排除

### 问题 1：找不到"允许不受信任的快捷指令"选项

**可能原因**：
- iOS 版本过低（需要 iOS 14+）
- 从未运行过快捷指令 App

**解决方案**：
1. 更新 iOS 到最新版本
2. 打开快捷指令 App，运行任意一个内置快捷指令
3. 重新进入设置查看

### 问题 2：快捷指令无法运行

**可能原因**：
- 权限未授予
- 快捷指令文件损坏
- iOS 版本不兼容

**解决方案**：
1. 检查并授予所有必要权限
2. 重新下载快捷指令文件
3. 更新 iOS 到最新版本

### 问题 3：无法检测到资源

**可能原因**：
- 页面未完全加载
- 资源是动态加载的
- 网站有防盗链措施

**解决方案**：
1. 刷新页面并等待完全加载
2. 滚动页面触发懒加载
3. 尝试其他网站

### 问题 4：下载失败

**可能原因**：
- 网络连接问题
- 服务器限制
- 存储空间不足

**解决方案**：
1. 检查网络连接
2. 尝试其他资源
3. 清理存储空间

### 问题 5：快捷指令运行缓慢

**可能原因**：
- 页面资源过多
- 网络速度慢
- 设备性能问题

**解决方案**：
1. 耐心等待
2. 使用 Wi-Fi 网络
3. 关闭其他应用释放内存

## ❓ 常见问题

### Q1: 支持哪些网站？
**A**: 理论上支持所有网站，但效果取决于网站结构。常见支持的网站包括：
- 视频网站（YouTube、Bilibili 等）
- 图片网站（Flickr、Unsplash 等）
- 新闻网站（包含多媒体内容）
- 文档网站（PDF、Word 等）

### Q2: 下载的文件在哪里？
**A**: 默认保存到：
- **iCloud Drive**：快捷指令 > 资源下载
- **本地存储**：文件 > 我的 iPhone > 资源下载

### Q3: 支持哪些文件格式？
**A**: 支持以下格式：
- **视频**：MP4、WebM、AVI、MOV、MKV、FLV
- **音频**：MP3、WAV、OGG、AAC、FLAC、M4A
- **图片**：JPG、PNG、GIF、WebP、SVG、BMP
- **文档**：PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX
- **压缩包**：ZIP、RAR、7Z、TAR、GZ

### Q4: 为什么某些资源无法下载？
**A**: 可能原因：
- 网站有防盗链措施
- 资源需要登录才能访问
- 资源是动态加载的
- 网络连接问题

### Q5: 如何提高检测成功率？
**A**: 建议：
- 确保页面完全加载
- 滚动页面触发懒加载
- 刷新页面后重新检测
- 使用桌面模式浏览（Safari 设置 > 请求桌面网站）
