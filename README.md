# 资源嗅探下载器

一款强大的浏览器插件，能够自动嗅探网页中的视频、音频、图片等资源，支持预览和批量下载。

**支持平台**：
- 🖥️ **桌面浏览器**：Chrome、Edge、Firefox、Opera、Brave、Vivaldi、Samsung Internet
- 📱 **iOS 设备**：iPhone/iPad（通过快捷指令实现）

## ✨ 功能特性

### 🔍 智能嗅探
- **自动检测**：浏览网页时自动检测可下载资源
- **多类型支持**：视频、音频、图片、文档、压缩包等
- **实时更新**：动态加载的资源也能及时捕获

### 🎬 资源预览
- **视频预览**：支持在线播放视频
- **音频预览**：支持在线播放音频
- **图片预览**：支持图片缩放查看
- **文件信息**：显示文件名、大小、类型等详细信息

### ⬇️ 下载管理
- **单个下载**：一键下载单个资源
- **批量下载**：选择多个资源批量下载
- **下载进度**：实时显示下载进度
- **下载历史**：记录下载历史，方便查找

### 🎨 界面设计
- **简洁美观**：现代化的 UI 设计
- **响应式布局**：适配不同屏幕尺寸
- **主题切换**：支持浅色/深色主题
- **多语言**：支持中文和英文

### ⚙️ 个性化设置
- **嗅探规则**：自定义检测的资源类型
- **过滤规则**：设置过滤条件，忽略不需要的资源
- **下载设置**：配置下载路径、并发数等
- **界面设置**：自定义界面外观

## 📦 安装方法

### Chrome 浏览器

1. 下载插件源码
2. 打开 Chrome，进入扩展管理页面 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件目录

### Edge 浏览器

1. 下载插件源码
2. 打开 Edge，进入扩展管理页面 `edge://extensions/`
3. 开启左下角的"开发人员模式"
4. 点击"加载解压缩"
5. 选择插件目录

### Firefox 浏览器

1. 下载插件源码
2. 打开 Firefox，进入调试页面 `about:debugging#/runtime/this-firefox`
3. 点击"临时载入附加组件"
4. 选择插件目录中的 `manifest.json` 文件
5. **注意**：Firefox 使用 Manifest V2/V3，某些 API 可能与 Chrome 有差异

### Opera 浏览器

1. 下载插件源码
2. 打开 Opera，进入扩展管理页面 `opera://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件目录
6. **注意**：Opera 完全兼容 Chrome 扩展

### Brave 浏览器

1. 下载插件源码
2. 打开 Brave，进入扩展管理页面 `brave://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件目录
6. **注意**：
   - Brave 完全兼容 Chrome 扩展
   - Shields 可能阻止某些功能，建议调整 Shields 设置
   - 某些网站可能需要添加到白名单

### Vivaldi 浏览器

1. 下载插件源码
2. 打开 Vivaldi，进入扩展管理页面 `vivaldi://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件目录
6. **注意**：
   - Vivaldi 完全兼容 Chrome 扩展
   - 高度可定制，某些设置可能影响插件功能

### Samsung Internet

1. 下载插件源码
2. 打开 Samsung Internet，进入扩展管理页面
3. 点击"加载已解压的扩展程序"
4. 选择插件目录
5. **注意**：
   - Samsung Internet 基于 Chromium，部分兼容 Chrome 扩展
   - 某些功能可能受限
   - 建议使用最新版本

### iOS 设备（iPhone/iPad）

由于 iOS 设备对浏览器扩展的支持非常有限，我们提供了基于 iOS 快捷指令（Shortcuts）的解决方案：

1. **启用不受信任的快捷指令**
   - 打开"设置" App
   - 进入"快捷指令"
   - 启用"允许不受信任的快捷指令"

2. **下载快捷指令文件**
   - 在 Safari 中访问本项目的 `ios` 目录
   - 下载 `ResourceSniffer.shortcut` 文件

3. **安装快捷指令**
   - 打开"快捷指令" App
   - 点击"我的快捷指令"
   - 点击 "+" 按钮，选择"添加不受信任的快捷指令"
   - 选择下载的文件

4. **添加到共享表单（可选）**
   - 在快捷指令 App 中找到"资源嗅探下载器"
   - 长按 > 详细信息 > 在共享表单中显示
   - 选择 Safari

5. **使用快捷指令**
   - 在 Safari 中打开包含资源的网页
   - 点击分享按钮，选择"资源嗅探下载器"
   - 选择要下载的资源

**注意**：
- iOS 快捷指令版本功能相对简单，主要支持资源检测和下载
- 不支持复杂的预览和批量操作
- 详细说明请查看 `ios/README.md` 和 `ios/INSTALL.md`

## 🚀 使用方法

### 基本使用

1. **浏览网页**：正常浏览网页，插件会自动检测资源
2. **查看资源**：点击浏览器工具栏中的插件图标
3. **选择资源**：在弹出窗口中选择需要下载的资源
4. **下载资源**：点击"下载选中"或"下载全部"按钮

### 资源筛选

- **类型筛选**：点击顶部的类型按钮筛选资源
- **搜索功能**：在搜索框中输入关键词搜索资源
- **排序功能**：选择按时间、大小、名称或类型排序

### 资源预览

1. 选择一个资源
2. 点击"预览"按钮或资源项上的眼睛图标
3. 在弹出的预览窗口中查看资源
4. 点击"下载"按钮直接下载

### 批量下载

1. 使用复选框选择多个资源
2. 或点击"全选"按钮选择所有资源
3. 点击"下载选中"按钮开始批量下载

## ⚙️ 设置说明

点击插件弹窗中的设置按钮，或右键点击插件图标选择"选项"进入设置页面。

### 嗅探设置

- **启用资源嗅探**：开启/关闭资源检测功能
- **检测的资源类型**：选择要检测的资源类型
- **最小文件大小**：忽略小于此大小的文件
- **最大文件大小**：忽略大于此大小的文件

### 下载设置

- **保存路径**：设置下载文件的保存位置
- **最大并发下载数**：同时下载的最大文件数量
- **显示保存对话框**：下载前是否显示"另存为"对话框
- **下载失败时重试**：下载失败后是否自动重试

### 界面设置

- **主题**：选择浅色、深色或跟随系统主题
- **语言**：选择界面语言
- **显示通知**：下载完成或失败时是否显示通知
- **显示徽章**：是否在插件图标上显示资源数量

### 过滤设置

- **阻止的域名**：不检测这些域名下的资源
- **自定义过滤规则**：使用正则表达式过滤资源 URL
