📝 测试说明

如何进行兼容性测试

  1. 确保插件已正确安装并启用
  2. 点击"运行所有测试"按钮
  3. 查看测试结果和浏览器信息
  4. 根据测试结果调整设置或反馈问题

常见问题及解决方案

  1. Brave 浏览器：如果功能受限，请检查 Shields 设置，尝试降低保护级别或将网站添加到白名单
  2. Firefox 浏览器：某些 API 可能与 Chrome 有差异，建议使用最新版本
  3. Samsung Internet：部分功能可能受限，建议使用桌面浏览器获得最佳体验
  4. Opera 浏览器：如果使用 VPN，可能会影响某些功能，建议关闭 VPN 测试
